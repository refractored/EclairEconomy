# Contributing

Thank you for contributing to this project! We welcome contributions!

# API

APIs should be written and accessible in both Kotlin and Java. Java APIs should be annotated with JetBrains annotations, and every parameter must be annotated with @NotNull or @Nullable.

# Credit

Credit for contributions may be provided on the project’s page.

Credit may also be provided in the plugin’s YAML file under a “Contributors” section, at the project owners’ discretion, based on whether the contribution is deemed significant.

The project owners may decline to credit contributions that are primarily generated by artificial intelligence unless the contributor documents and demonstrates substantial human authorship and substantial human modification.
